# CA70B – Mobile Applications Development Lab

## Lab Experiment Details

# Part A: Android Application Development

## Experiment 1: GUI Components, Layouts and Event Handling

### Aim
Develop an Android application to design a student registration form using suitable GUI components, fonts, colours and layout managers. Implement appropriate event listeners to validate the entered data and display the submitted information.

---

## Experiment 2: Calculator Application

### Aim
Develop an Android calculator application to perform basic arithmetic operations such as addition, subtraction, multiplication and division. Provide appropriate input validation and display suitable error messages for invalid input and division by zero.

---

## Experiment 3: Graphical Primitives

### Aim
Develop an Android application to display basic graphical primitives such as lines, rectangles, circles, ovals, arcs and text using the Canvas and Paint classes.

---

## Experiment 4: SQLite Database Application

### Aim
Develop an Android application for managing student records using an SQLite database. The application should support inserting, viewing, searching, updating and deleting records.

---

## Experiment 5: Multithreading

### Aim
Develop an Android application that performs a time-consuming operation in a background thread without blocking the user interface. Display the progress of the operation and show an appropriate message after the task is completed.

---

## Experiment 6: GPS-Based Location Application

### Aim
Develop a native Android application that obtains the current geographical location of the user using GPS. Display the latitude and longitude of the current location and indicate the location on Google Maps.

---

## Experiment 7: Message Alert Application

### Aim
Develop an Android application that creates an alert upon receiving a message. Display the received message information and generate an appropriate notification to the user.

---

# Part B: iOS Application Development

## Experiment 8: iOS User Interface Development

### Aim
Develop an iOS application to create a user registration or profile interface using UIKit with Auto Layout and SwiftUI. Validate the user input and display the submitted information on the screen.

---

## Experiment 9: Data Persistence Using Core Data

### Aim
Develop an iOS application for managing contact or task information using Core Data. The application should support saving, retrieving, displaying, updating and deleting records.

---

## Experiment 10: Location-Based iOS Application

### Aim
Develop an iOS location-based application using Core Location and MapKit. Obtain the current latitude and longitude of the user and display the location on a map with an appropriate annotation.

---
